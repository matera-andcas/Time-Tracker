🎯 PRÓXIMOS PASSOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  INSTALAR DEPENDÊNCIAS
    
    Execute o script de instalação:
    $ ./install.sh
    
    Ou manualmente:
    $ sudo apt install python3-venv python3-full
    $ python3 -m venv venv
    $ source venv/bin/activate
    $ pip install PyQt6


2️⃣  VERIFICAR INSTALAÇÃO
    
    $ source venv/bin/activate
    $ python3 -c "import PyQt6; print('✅ PyQt6 instalado!')"


3️⃣  EXECUTAR TESTES
    
    $ source venv/bin/activate
    $ python3 test.py
    
    Você deve ver:
    ✅ TODOS OS TESTES PASSARAM!


4️⃣  EXECUTAR APLICAÇÃO
    
    $ ./run.sh
    
    Ou diretamente:
    $ source venv/bin/activate
    $ python3 main.py


💡 DICAS DE USO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Clique em ▶ (verde) para iniciar o timer
✓ Clique em ⏸ (vermelho) para pausar
✓ Use checkboxes para selecionar e deletar
✓ "Select All" marca/desmarca todos os cards
✓ Múltiplos timers podem rodar simultaneamente

🐛 SOLUÇÃO DE PROBLEMAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problema: externally-managed-environment
Solução:  $ ./install.sh (cria ambiente virtual automaticamente)

Problema: PyQt6 não encontrado
Solução:  $ source venv/bin/activate
          $ pip install PyQt6

Problema: python3-venv não encontrado
Solução:  $ sudo apt install python3-venv python3-full

Problema: Permissão negada nos scripts
Solução:  $ chmod +x install.sh run.sh

Problema: Aplicação não abre
Solução:  Verifique se DISPLAY está configurado (para X11)
          $ source venv/bin/activate
          $ python3 main.py
